download.net launcher v1 brings Nuttyinc’s community app and game store to Windows.

- Electron launcher with apps, games, search, and verified downloads.
- Nuttyinc account login and signup through the Aspire backend.
- GitHub-token publishing creates a fork, public .vfdn folder package, and review pull request.
- Complete portable launcher folder ZIP and MIT license agreement.
- Whole-folder app publishing, vfdn.ps1 build command, and verified installation into Programs.
- Code of conduct and contributing pages with scroll-and-hold acknowledgment.

[Download the latest nightly build](https://nightly.link/nuttyinc/download.net/workflows/nightly.yml/main/download.net-launcher-v1.zip)

Nightly artifacts expire after 30 days. The folder ZIP attached to this tagged release remains available. Extract all files together and open download.net.exe. Configure the API and Bootstrap addresses in Settings after installing. No public Nuttyinc backend is bundled. The initial catalog contains no approved apps. The local launcher build is unsigned; production code signing can be added through electron-builder’s signing configuration.
